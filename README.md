# ENTERPRISE 360

Plataforma inteligente de gestión empresarial basada en una arquitectura de microservicios.

## Tecnologías principales

- Java 21 + Spring Boot
- Angular + TypeScript
- Flutter + Dart
- Python + FastAPI
- Apache Kafka
- PostgreSQL
- Redis
- Docker
- Microsoft Azure

## Arquitectura

Microservicios + Event-Driven Architecture.

## Módulos

- Autenticación y autorización
- Gestión empresarial
- Usuarios y roles
- Productos e inventario
- Almacenes
- Pedidos
- Ventas
- Logística
- Inteligencia artificial
